## 🚀 What is GambleNumbers?

GambleNumbers is a **Bitcoin and Bitcoin Cash trading simulator** built for education. It uses **real historical and live market data** (from Binance, Kraken, and Coinbase via SQL Server) to let students and beginners practice trading strategies without risking any real money.

The platform is designed for:
- 🏫 **Schools and universities** teaching financial literacy and crypto basics
- 📚 **Online courses** on cryptocurrency investment
- 👨‍💻 **Developers and curious users** who want to understand how crypto markets work
- 💡 **Self-learners** exploring buy-low, sell-high strategies risk-free

## ✨ Features

### 📊 Real-Time Market Data
- Live price feeds from **Binance, Kraken, and Coinbase**
- Prices in **BRL (R$) and USD ($)** simultaneously
- Automatic refresh every few seconds
- Highlights the exchange with the **highest profit potential**

### 📈 Interactive Price Chart
- Timeframes: **5M, 10M, 20M, 30M, 1H, 6H, 1D, 7D, 30D, 60D, 90D, 120D, 180D, 220D, 1Y, 2Y, 3Y, 5Y**
- **Confirmed historical data** + **statistical price forecast**
- Multi-line chart comparing all exchanges simultaneously
- Hover tooltips with price, date/time, and action hints

### 🛒 Simulated Buy & Sell Operations
- **Right-click on any historical point** → register a simulated buy
- **Left-click on any projected point** → schedule a simulated sell
- Multiple lots open simultaneously (LT1, LT2, LT3...)
- Color-coded: 🟢 profit | 🔴 loss on projected sells
- Weighted average price calculation across all open lots

### 🔮 Statistical Price Forecast
- Algorithm based on historical min/max delta bands
- Adjustable target return slider (1% to 20%+)
- Auto-calculated **target sell price**

### 💼 Portfolio Panel
- Buy/sell amount • Stop-loss • Target price
- Open lots counter • Weighted average price
- Total projected profit • Current return %

### 📋 Operations Log Table
- Full history of all simulated buys and scheduled sells
- Columns: Lot, Type, Date/Time UTC, Price (BRL), BTC, Value, Result, Return %
- Conditional sell countdown • Bulk clear options

### 💱 Multi-Asset & Multi-Currency
- **Bitcoin (BTC)** and **Bitcoin Cash (BCH)**
- Quote in **BRL** or **USD**

## 🎓 Educational Goals

> **"Learn by doing — without the consequences."**

### For Schools & Courses
- Demonstrate how crypto price charts work in real time
- Teach students to identify **buy opportunities** (dips) and **sell targets** (peaks)
- Show **lot averaging** — buying more at lower prices reduces average cost
- Explain **stop-loss** as a risk management tool
- Introduce **statistical forecasting** vs confirmed data

### Key Lessons
1. Time in the market matters — longer timeframes reveal trends
2. Buy low / sell high is harder than it looks
3. Emotional discipline — practice patience without real stakes
4. Reading charts — averages, projections, exchange comparison
5. Exchange spreads — different platforms, different prices

---

## 🔧 How to Use

1. Select your asset — **BTC** or **BCH**
2. Choose a timeframe — start with **90D** to see clear trends
3. Enter your simulated budget (e.g. R$ 55,000)
4. **Right-click chart lows** → register buy operations
5. **Left-click projected highs** → schedule sell targets
6. Watch the **operations table** to track P&L in real time
7. Adjust **desired return %** with the slider

## 📦 Stack

- **Frontend**: Angular + Chart.js
- **Backend**: PHP + SQL Server
- **Data**: Binance, Kraken, Coinbase APIs
